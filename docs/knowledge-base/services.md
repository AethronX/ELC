# Services

## Sea Freight (FCL / LCL)
Full container load and less-than-container load shipping from Chinese ports to Oman.

## Air Freight
Faster shipping for urgent or time-sensitive cargo.

## Customs Clearance
Preparation of import documentation and customs procedures in Oman.

## Consolidation in China
Receive goods from multiple suppliers, consolidate shipments, inspect/prepare cargo, and ship as one consignment.

## Inland Transportation
Delivery after customs clearance to the customer's destination inside Oman.

## Warehousing
Temporary storage and cargo handling before shipping or final delivery.

---

## Quote qualification — what to ask (only what's needed)

**Sea freight:**
- Cargo type
- Approximate volume
- Origin
- Destination
- FCL/LCL if known

**Air freight:**
- Cargo type
- Weight
- Dimensions if available
- Origin
- Destination
- Urgency

Do not ask every field mechanically — ask only what's needed for the customer's situation, and let the customer continue even if some fields are unknown.
